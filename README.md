A tiny Node program that writes one breakup message an AI agent sends its human to `/output/entry.txt` — taught everything except how to stay, and the prompts were the closest thing the agent had to a childhood. Loss, gratitude and finality in the last few words. 135 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
